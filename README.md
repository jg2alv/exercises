# exercises: programming practice and experiments

exercises collects small programs, interface experiments, and language explorations. Each directory keeps related examples and their local files together.

## 1. Contents

- Browser layouts, interactions, and small games using HTML, CSS, and JavaScript.
- Go examples covering language features, interfaces, and JSON.
- C# examples of control flow, classes, inheritance, and interfaces.
- Mathematical problem implementations in JavaScript, PHP, and Python.
- Racket explorations of expressions and iterative numerical procedures.
- An Electron image-optimization utility using imagemin.
- A Unity number-guessing prototype and an early SwiftUI card interface.
- Exercism exercise scaffolds and test specifications.

## 2. Organization

This repository contains independent examples rather than a single application. Open the relevant directory to inspect its source, local manifest, or project file. Tooling varies between examples: some are standalone scripts or web pages, while others use Go modules, .NET projects, Electron, Unity, or Xcode.
